# 童站挑战剪辑器

把「手动滚轮打点 → 审核标错 → 导出带 ✅/❌ + 编号 + 对错音效的切片」整条链路，
包成一个**本地网页工具**：双击启动，浏览器里点按钮即可完成，
不需要复制 ffmpeg 命令到外部终端去跑。

- 纯 Node 内置模块实现的服务端（零 npm 依赖）
- 前端是单个 `public/index.html`，视频边看边打点
- 切片、烧录、合并全部调本机 ffmpeg

## 快速开始

双击 **`启动.cmd`**（纯英文名兜底 `start.cmd`）：

1. 自动挑一个空闲端口（从 8777 起）
2. 启动本地服务
3. 等就绪后自动打开浏览器

关闭那个黑窗口 = 停止服务。启动细节写在 `_launcher.log`，起不来时先看它。

### 前置条件

| 依赖 | 说明 |
| --- | --- |
| **Node.js 18+** | 启动器优先用 PATH 里的 `node`，找不到时回落到内置路径 |
| **ffmpeg / ffprobe** | 必须在 PATH 中（本项目开发机在 `F:\ffmpeg-4.4.1-full_build\bin`） |
| **Python + Pillow** | 烧录 ✅/❌ 标记图需要，可用环境变量 `CUT_PY` 指定解释器 |

页面右上角有自检，会显示 `ffmpeg ✔ / PIL ✔`。

## 功能

- **手动打点**：鼠标滚轮下滑 / 手机下滑 / 快捷键（默认 `M` 打点、`E` 标错，键位可改）
- **审核栏**贴在视频右侧：逐段标 ✅/❌、跳转 / 截断 / 删点、一键全部反选
- **起点 / 结尾**：只导出中间那一段，编号从起点重新从 1 开始
- **自动存档**：打点结果自动保存，刷新或崩溃都不丢；也支持导出 / 导入打点文件
- **烧录标记**：✅/❌ + 编号（出现 / 消失时间可分别设置）+ 对错音效（原声保持）
- **一键成片**：导出后自动合并成一条视频，也可单独执行「合并成片」

> 设计取舍：`silencedetect` 自动切分实测不准，已改为**以手动打点为准**；
> OCR 自动判定也已移除，改为**人工逐段标错**。编号不再走 ASS 字幕，
> 而是直接烧进画面（相关代码仍保留在 `server.js` 中备用）。

## 目录结构

```
启动.cmd / start.cmd   双击启动
launcher.js            启动助手（挑端口 / 起服务 / 就绪后开浏览器）
server.js              本地服务（零依赖，仅用 Node 内置模块）
overlay_gen.py         生成 ✅/❌ + 编号标记图（Pillow）
ocr_worker.py          早期 OCR 判定脚本，现已不在流程中，留作备用
pick_file.ps1          调用 Windows 原生文件对话框
public/index.html      前端页面（打点 / 审核 / 导出全在这里）
assets/                对.mp3 / 错.mp3（可整体替换成自己的音效）
使用说明.md            完整说明，建议先读这个
```

## 输出位置

默认输出目录 `F:\workbuddy\2026-10-02-12-47-05\output\manual`，可用环境变量覆盖。

```
<输出目录>\clips_burned\        烧录好的切片（✅/❌ + 编号 + 对错音效）
<输出目录>\clips\               干净切片（可选）
<输出目录>\童站挑战_xxx.mp4     合并好的成片
<输出目录>\manifest.json        本次导出清单
```

## 环境变量

| 变量 | 作用 |
| --- | --- |
| `CUT_OUT_DIR` | 默认输出目录 |
| `CUT_SFX_OK` / `CUT_SFX_NO` | 自定义对 / 错音效文件 |
| `CUT_PORT` | 固定端口 |
| `CUT_CONC` | 导出并发数 |
| `CUT_PY` | 指定 Python 解释器路径 |
