# 童站挑战剪辑器

把「手动滚轮打点 → 审核标错 → 导出带 ✅/❌ + 编号 + 对错音效的切片」整条链路，
包成一个**本地网页工具**：双击启动，浏览器里点按钮即可完成，
不需要复制 ffmpeg 命令到外部终端去跑。

- 纯 Node 内置模块实现的服务端（零 npm 依赖）
- 前端是单个 `public/index.html`，视频边看边打点
- 切片、烧录、合并全部调本机 ffmpeg

## 快速开始

双击 **`启动.cmd`**（纯英文名兜底 `start.cmd`）：

1. 自动挑一个空闲端口（从 8777 起）
2. 启动本地服务，**先做一次环境自检**并打印 ffmpeg 状态与实际路径
3. 等就绪后自动打开浏览器

关闭那个黑窗口 = 停止服务。启动细节写在 `_launcher.log`，起不来时先看它。

## 依赖

| 依赖 | 必须吗 | 说明 |
| --- | --- | --- |
| **Node.js 18+** | 必须 | 只用来起本地服务。启动器按 `runtime\node` → PATH → `C:\Program Files\nodejs` → 用户目录 → 兜底路径 顺序查找 |
| **ffmpeg** | 导出必须 | 打点 / 审核 / 存档 / 导入打点都不需要它。自动探测：`CUT_FFMPEG` → PATH → 工具目录 `ffmpeg\bin` → 常见位置 → **扫描本机**（很多人的电脑里其实有，比如录屏软件自带的） |
| ~~Python + Pillow~~ | **不再需要** | ✅/❌ + 编号 改由页面用 canvas 渲染，换电脑只要搞定 ffmpeg 一个东西 |

**缺 ffmpeg 也能打开页面**——打点、审核、存档、导出 / 导入打点全都正常，
只是「导出成片」不可用；页面顶部会有红色横幅直接写着怎么装。

也可以双击 **`安装依赖.cmd`** 一键装 ffmpeg：自动下载官方压缩包（约 80MB，只下一次）
→ 解压到 `工具目录\ffmpeg\bin\`（**不改 PATH、不需要管理员**）→ 自动复检。
国内下载慢的话，自己下好 zip 改名 `ffmpeg.zip` 放进工具目录，脚本会走离线安装。

> 两个 `.cmd` 里故意**不写中文**（全是英文注释）：批处理含中文时，
> 在代码页不是 UTF-8 的电脑上会被解析乱掉，表现为满屏「'xxx' 不是内部或外部命令」。
> 中文提示统一由 Node 打印。

## 功能

- **手动打点**：鼠标滚轮下滑 / 手机下滑 / 快捷键（默认 `M` 打点、`E` 标错，键位可改）
- **审核栏**贴在视频右侧：逐段标 ✅/❌、跳转 / 截断 / 删点、一键全部反选
- **按帧微调**：选中切点后 ±1/±5/±10 帧挪动，可自定义 N 帧、拉条实时拖；
  视频右侧另有一条小号微调条；支持吸附（整帧 / 关键帧 / 不吸附），快捷键 `,` `.`（Shift 一次 5 帧）
- **起点 / 结尾**：只导出中间那一段，编号从起点重新从 1 开始
- **自动存档**：打点结果自动保存，刷新或崩溃都不丢；也支持导出 / 导入打点文件
- **烧录标记**：✅/❌ + 编号（符号与编号的出现 / 消失时间可分别设置）+ 对错音效（原声保持）
- **一键成片**：导出后自动合并成一条视频，也可单独执行「合并成片」

### 标记图是怎么来的

✅/❌ 符号 + 编号在**页面里用 canvas 画**（矢量绿勾 / 红叉或系统表情，描边、字号、
九宫格位置、上下顺序都与设置面板一一对应），画好上传给本地服务，导出时由 ffmpeg 叠加到画面上。
好处：预览就是成片（同一段代码），换电脑不用装 Python，也不用等 Python 起进程。

> 设计取舍：`silencedetect` 自动切分实测不准，已改为**以手动打点为准**；
> OCR 自动判定也已移除，改为**人工逐段标错**。编号不再走 ASS 字幕，而是直接烧进画面。

## 目录结构

```
启动.cmd / start.cmd          双击启动（内容一样，互为兜底；纯 ASCII）
安装依赖.cmd / setup-deps.cmd  双击装 ffmpeg（纯 ASCII）
launcher.js                   启动助手（挑端口 / 起服务 / 环境自检 / 就绪后开浏览器）
setup-deps.js                 依赖安装（下载 + 解压 + 复检，纯 Node，不需要 PowerShell）
findtools.js                  依赖探测（PATH / 工具目录 / 常见位置 / 扫描本机 + 缓存）
server.js                     本地服务（零依赖，只用 Node 内置模块）
public/index.html             前端页面（打点 / 审核 / 标记渲染 / 导出）
assets/                       对.mp3 / 错.mp3（可整体替换成自己的音效）
overlay_gen.py / ocr_worker.py  历史脚本（现在流程用不到，留着备用）
pick_file.ps1                 调 Windows 原生文件对话框（可选功能）
使用说明.md                   完整说明，建议先读这个
```

> 关于发行包：另有 `完整版` 内置了 Node 和 ffmpeg，解压即用、什么都不用装；
> 本仓库是**轻量版**（只有工具本体），依赖由上面的脚本自动搞定。

## 输出位置

默认输出目录为 `桌面\童站挑战输出`（若本机存在开发机路径则优先用它），可用环境变量覆盖。

```
<输出目录>\clips_burned\        烧录好的切片（✅/❌ + 编号 + 对错音效）
<输出目录>\clips\               干净切片（可选）
<输出目录>\童站挑战_xxx.mp4     合并好的成片
<输出目录>\manifest.json        本次导出清单
```

## 环境变量

| 变量 | 作用 |
| --- | --- |
| `CUT_OUT_DIR` | 默认输出目录 |
| `CUT_SFX_OK` / `CUT_SFX_NO` | 自定义对 / 错音效文件 |
| `CUT_PORT` | 固定端口 |
| `CUT_CONC` | 导出并发数 |
| `CUT_FFMPEG` | 指定 ffmpeg 路径 |
| `TOOL_NO_SCAN` | 设为 `1` 则不扫描本机找 ffmpeg |
| `TOOL_SCAN_MS` | 扫描预算毫秒数（默认 15000） |
| `TOOL_NO_DEV_FALLBACK` | 设为 `1` 跳过开发机兜底路径，模拟别人电脑的环境 |
